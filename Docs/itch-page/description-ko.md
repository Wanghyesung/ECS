# 쏘고, 고르고, 다시 건다.

몰려오는 적을 돌파하며 카드를 고르세요. 안전하게 성장할 수도 있고, 조커에 한 번 더 걸어 더 강한 빌드를 노릴 수도 있습니다.

**오비탈**은 짧게 반복되는 전투와 카드 성장에 집중한 3D 슈팅 로그라이트입니다. 적을 쓰러뜨리고 경험치를 모아 세 장의 후보 중 하나를 선택하세요.

더 큰 보상을 원한다면 **조커 카드 도박**에 도전하세요. 연속 성공하면 더 좋은 카드를 노릴 수 있지만, 실패하면 쌓아 둔 카드와 이미 얻은 카드까지 잃을 수 있습니다.

## 플레이 특징

- 몰려오는 적과 보스를 상대하는 3D 슈팅 전투
- 레벨업마다 카드 3장 중 하나를 고르는 성장
- 도전, 누적, 확정 또는 손실로 이어지는 조커 카드 시스템
- 매 런 다른 조합을 만드는 장비와 카드 빌드

**한 번 더 걸 것인가, 지금 살아남을 것인가.**

## 설치 안내

Windows ZIP 파일의 압축을 풀고 게임 실행 파일을 실행하세요.
