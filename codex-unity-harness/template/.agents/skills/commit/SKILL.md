# $commit

1. `git status --short`와 diff를 읽고 이번 작업 파일만 선택한다. 기존 사용자 변경을 섞지 않는다.
2. 제목은 `[Fix]`, `[Feature]`, `[Refactor]`, `[Docs]`, `[Chore]` 중 맞는 태그와 구체적인 요약을 사용한다.
3. 본문에는 변경 이유, 핵심 변경, 검증 결과를 불릿으로 적는다.
4. 저장소 훅이 일반 커밋을 차단하므로 기본적으로 사용자에게 실행할 명령과 메시지를 제공한다. 명시적 자동 실행 절차가 승인된 경우에만 그 범위에서 커밋한다.
